# Overview
2D/3D Game engine written in the Odin programming language.
This is a rewrite of the C++ version of the engine.

## How to use
A small example with build script and all can be found in [examples/001_Hello_World/](./examples/001_Hello_World/)

You can simply download the library and include the runtime/ module folder into your project as a collection or not:
```sh
odin run . -collection:vane=/path/to/vane/runtime
```
